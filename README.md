# 📝 Interactive To-Do List

A responsive and interactive To-Do List application built using HTML, CSS, and JavaScript. This project helps users manage daily tasks with a clean design that works across mobile phones, tablets, and desktop screens.

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 📊 Track total, completed, and remaining tasks
- 🔍 Filter tasks by All, Completed, and Remaining
- 🧹 Clear completed tasks
- 💾 Save tasks using localStorage
- 🌙 Switch between dark and light modes
- 📱 Responsive mobile, tablet, and desktop layouts
- 📂 Interactive mobile navigation menu
- 🎨 Font Awesome icons
- 📭 Empty-state design when no tasks exist

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Browser localStorage

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Start adding and managing your tasks!

## 🎯 Project Goal

The goal of this project was to practice DOM manipulation, event handling, arrays, objects, localStorage, and responsive web design.
